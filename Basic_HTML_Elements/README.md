# Basic HTML Elements Practice

## Problem Statement

In this assignment, practice the basic HTML elements by applying the concepts learned so far.

Create a webpage that displays:

- A paragraph: Coding opens up a universe of possibilities, empowering you to create and innovate.

Refer to the provided reference image for the expected output.
